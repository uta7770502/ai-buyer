# Preview接続の準備（2026-10-26）

Productionに登録済みの認証情報と、Previewに設定された情報は別です。
現在のPreviewにはShopifyの認証・暗号化情報とRedisトークンが不足しています。
秘密情報をレポートへ出力したり、Productionから無断でコピーしないでください。

## 保存先

PreviewのShopify OAuthセッションと法務フォームは、VERCEL_ENV=previewと
VERCEL_GIT_COMMIT_REFから生成したブランチ別キーで保存します。
ブランチが不明な場合は読み書きを停止します。本番キーへのフォールバックはしません。
Productionの既存キーは変更せず、登録済み情報を維持します。
この変更以前のPreview専用データがある場合、自動移行は行いません。

注文・追跡・照合のキーはまだ環境別ではありません。
この修正だけを理由に本番RedisをPreviewと共有してはいけません。
Preview専用Redisと専用の32バイト暗号化キーを用意し、秘密情報は管理画面で設定します。
既存のPreviewのRedis URLはProductionと同じ設定なので、専用URLとトークンの両方が必要です。

## 接続後の確認順序

1. Previewスコープに専用Redis URL・トークン・暗号化キーを設定する。
2. Shopifyの開発用アプリ・検証用ストアが利用できるか確認し、対応する認証情報と
   PreviewのOAuthリダイレクトURLを設定する。実店舗への接続・認証情報共有は別途判断する。
3. Previewだけを再デプロイし、OAuth接続を行う。
4. 接続診断、下書き監査、在庫ドライラン、注文照合の読み取りを実行する。
5. Shopifyへの更新を伴う在庫同期は対象と影響を確認してから検証する。

秘密情報を保存しただけでは動作確認完了ではありません。
実注文、商品ACTIVE化、本番公開、Checkout・広告有効化、パスワード解除、mainマージは実行しません。
